AITEST8.0 使用教程

本版按“检测 → 选择全局或项目目录 → 安装技能 → 重新加载模型工具 → 在对话中调用”的顺序工作。安装结果会显示目标路径，只有复制成功才记为成功。

一、首次使用与订阅

  1. 首次启动，阅读并勾选同意《使用规则》。
  2. 联网开始一次 3 分钟体验，关闭程序不会暂停计时。
  3. 购买 7 天、30 天或 360 天注册码，将设备码发给客服。
  4. 粘贴注册码，再次确认规则并激活。续费从现有到期时间顺延。

二、模型工具教程

产品识别与安装安装后使用
Claude Code检测 Claude 配置；技能写入用户或项目技能目录。重启会话，让 Claude 读取 SKILL.md，明确要求按 reverse-flow-skill 执行。
Codex / ChatGPT全局写入 ~/.codex/skills；项目可写入项目技能目录。重开任务或刷新技能列表，直接点名技能。
CodeBuddy检测 CodeBuddy 配置目录并复制技能。重新打开工作区，在 Agent 对话中引用技能名。
Trae / Trae CN分别识别国际版与中国版配置，互不混写。重载窗口后在 Agent 模式说明要使用已安装技能。
Claude Haha使用该产品自己的用户或项目目录。重启应用并在新会话中调用技能。
Qoder检测 Qoder 配置，支持全局和项目安装。重新加载项目后从 Agent 会话调用。
Cursor检测 Cursor；项目技能随当前工程保存。重载窗口，在 Agent 模式点名技能或引用其文件。
WorkBuddy检测 WorkBuddy 配置并安装到独立目录。重新启动对应工作区后调用。
Gemini CLI检测 Gemini 用户目录；项目安装随仓库保存。在项目中新建会话，要求读取技能说明。
GitHub Copilot安装到 Copilot 支持的项目技能位置。重载 VS Code，再从 Copilot Chat 调用。
Kiro检测 Kiro 配置与项目目录。重新打开工作区，在 Agent 会话使用。
通用 Agent Skills对支持开放 Agent Skills 目录结构的新工具使用通用适配器。安装后查看工具文档要求的刷新方法，再点名技能。
未探测到的未来产品：先使用“通用 Agent Skills”选择项目目录。若产品不读取标准 SKILL.md，使用“Agent / Skill 模板库”复制内容到该产品的自定义规则或 Agent 提示区域。界面不会把未验证的产品显示为已兼容。

三、技能管理

“安装内置逆向技能”安装完整技能；“管理技能 / 加载新技能”可导入本地技能目录。逆向技能中的脚本、参考资料和 SKILL.md会作为一个整体复制。

在线共享技能池尚未迁移到 AITEST8.0 服务。当前可靠功能是内置技能、本地导入、安装和卸载。

四、我的消息

菜单“我的消息”从授权站点读取作者发布的签名消息。内容经过签名验证，网络异常时会明确显示读取失败。

五、在线更新

菜单“在线更新”读取签名发布清单。发现新版后可下载 ZIP，程序会核验 SHA-256。把新包上传到授权站点的下载目录，并更新签名发布清单后，客户端才能看到新版；只把文件丢在本机目录不会自动同步。下载完成后关闭旧版、解压新版并运行。

六、需要帮助

如果模型工具未显示、技能没有生效、激活失败或在线功能无法使用，请点击“订阅与续费”中的客服入口联系技术支持，并说明所用模型工具和界面提示。

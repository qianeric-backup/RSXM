# RSXM AI 渗透测试工具软件 — 用户手册

版本：V2.8.0
适用平台：Android 7.0 及以上（arm64）

---

## 1. 软件概述

### 1.1 软件定位

RSXM AI 渗透测试工具软件（以下简称 RSXM）是一款运行于 Android 移动终端的
轻量级 AI 渗透测试（安全测试）辅助工具。软件在移动设备内置的 Linux 虚拟环境
（proot 技术，无需 Root 亦可运行）中完整部署 AI 智能体运行环境（reasonix），
提供本地化智能体会话、代码生成、命令执行能力，并集成提示词工程与能力增强
中心、漏洞扫描（CVE/CNVD 漏洞库自动拉取）、设备调试与系统管理等安全测试
配套功能。

### 1.2 运行环境

| 项目 | 要求 |
|---|---|
| 宿主系统 | Android 7.0 及以上（arm64 架构） |
| 内置虚拟环境 | Alpine Linux（proot 用户态模拟，免 Root） |
| 网络 | 首次部署需网络；reasonix 调用 API / DS2API 需联网；漏洞库拉取需联网 |

### 1.3 安装方式

- 通过 GitHub Release 下载 `app-release-V2.8.0.apk` 安装；
- 首次启动自动部署内置运行环境（约 1-2 分钟），期间请保持屏幕常亮。

---

## 2. 快速开始

1. 启动 RSXM，等待环境部署完成；
2. 进入「API Key」配置 DeepSeek 等模型密钥（会话使用）；
3. 进入「会话」启动 serve 引擎（约 10-30 秒自动就绪）；
4. 在会话中与 AI 智能体对话，或通过终端面板执行命令。

### 2.1 首次启动常见提示

| 提示 | 处理 |
|---|---|
| 「环境部署中」 | 等待完成，勿切换应用 |
| 「serve 未在线」 | 点「启动」或等待看门狗自愈（约 20 秒轮询） |
| 「ADB 未连接」 | 开启开发者选项→无线调试→配对（填写配对端口与配对码） |

## 3. 功能操作

### 3.1 设备调试与系统管理（ADB / Root）

- 侧滑菜单「ADB」：无线调试配对、连接状态检测、adb 命令执行；
- 「ROOT」：以 root 权限运行宿主命令（root id、root 'pm list packages'）；
- 项目面板：工作目录管理、项目文件操作。

### 3.2 智能体会话服务（serve）

- 自动/手动启动 serve 引擎（127.0.0.1:8787，token 鉴权）；
- 历史会话记录、消息提交、运行状态实时刷新；
- 引擎异常自动重启（看门狗 20 秒轮询 + 退避重试）。

### 3.3 提示词工程与能力增强中心（破甲中心）

- 一键部署：破甲内核注入配置文件（[agent] system_prompt）与常驻指令文件
  （REASONIX.md 双载体：全局 ~/.reasonix/REASONIX.md + 项目 /root/REASONIX.md）；
- 指令编辑：自定义提示词保存/应用/恢复内置模板；
- 状态显示：config 标记与 REASONIX.md 锚点任一命中即显示已注入；
- 一键还原：移除双载体（重启环境后生效）。

### 3.4 AI 代理安全策略配置台（dsh purge 清洗）

- 补丁管理：破甲 system_prompt / 权限白名单 / Guardian 禁用 / Full access
  审批 / 全局指令，逐项应用/还原，实时状态；
- 提示词页签：编辑 ~/.reasonix/break-armor-prompt.md 并应用为 system_prompt。

### 3.5 AI 开发工具集成套件（AI 破甲工具箱 / AITEST8）

- 破甲中心（3.3 节统一入口）；
- 技能池：内置技能（逆向流/红队/免杀/反编译）部署状态查看与一键部署；
- IDE 目标：10 个 IDE 破甲目标（默认折叠摘要、点开展开）；
- 共享技能池：Gitee Token 配置、技能同步。

### 3.6 漏洞扫描与漏洞库（v2.8.0）

侧滑菜单「漏洞扫描」：

1. 填写扫描目标（IP 或域名）；
2. 端口列表（默认常用 31 端口，可自定义，逗号分隔）；
3. 点「开始扫描」：并发 40 线程 TCP 探测 + Banner 抓取；
4. 结果按端口展示：端口 / Banner / 命中的 CVE/CNVD 条目（编号、名称、等级、描述）；
5. 点「更新漏洞库」：自动拉取 CVE（NVD API v2.0，最近 90 天高危）与 CNVD
   （官网列表页）增量入库，按编号去重，持久化于设备内。

### 3.7 其它功能

- API Key 配置：DeepSeek 等多模型接入；
- GitHub 更新：Release 通道版本检查、下载、安装；
- DS2API：DeepSeek API 网关配置；
- 终端：内置 xterm.js 终端（PTY 桥接），支持命令输入与终端尺寸自适应；
- 高级设置：SKILL、MCP、YOLO 免审批、后台运行、滑动速度等。

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 环境启动失败 | 检查网络，重启应用；看门狗会自动重试部署 |
| serve 启动无日志 | 已修复的 pkill 自杀问题（v2.4.1）：点「启动」重试 |
| 漏洞库更新失败 | NVD 匿名限速 5s/请求，稍后重试；CNVD 失败自动降级不影响 CVE |
| 破甲状态未显示已注入 | 点「一键部署破甲」后重启环境生效 |

---

## 5. 技术规格附录

- 开发语言：Java（Android 原生）、Python、Shell；
- 虚拟化：proot 用户态模拟 + PTY 桥接 + xterm.js 终端；
- 存储：reasonix 运行时与 pty-bridge 以 xz 压缩内置（部署时流式解压）；
- 漏洞库：内置种子 50 条 + NVD(CVE)/CNVD 增量；
- 常驻指令：AGENTS.md / REASONIX.md / CLAUDE.md 原生加载（用户全局 → 项目）。

## 二、源程序鉴别材料（必交，最关键）

### 2.1 硬性规格

| 项目 | 要求 | 说明 |
|---|---|---|
| 页数 | 前 30 页 + 后 30 页 = 60 页 | 源程序不足 60 页全交；超过则取前后各 30 页 |
| 每页行数 | 不少于 50 行 | 除最后一页外；建议统一 50 行/页排版 |
| 页眉 | 软件名称 + 版本号 | 每页顶部居中：`RSXM AI 渗透测试工具软件 V2.8.0` |
| 页码 | 右上角（或页脚居中） | 连续编号 1-60 |
| 字号 | 不小于 5 号（9pt） | 建议小五/五号，等宽字体（Consolas/等线） |
| 内容 | 纯源代码文本 | 无语法高亮、无水印；注释可保留 |
| 格式 | PDF（线上）/ 纸质 A4（窗口） | 线上系统直接传 PDF |

### 2.2 取哪些代码（推荐）

总量 11982 行（8 个 Java 源文件），按「主程序前后各 1500 行」组织：

| 页 | 来源 | 内容 |
|---|---|---|
| 1-30 | MainActivity.java 第 1-1500 行 | 主界面框架、菜单路由、环境启动 |
| 31-60 | MainActivity.java 第 9319-10819 行 | 终端、serve 引擎、漏洞扫描、破甲中心尾部 |

> 主程序单一文件连续取前后段，最能体现代码真实性与完整性；
> 若希望覆盖多文件，可前 30 页=MainActivity 头部、后 30 页=MainActivity 尾部，
> 中间文件（ReasonixServe/TranscriptClient 等）不必须入鉴别材料。

### 2.3 生成方式

仓库内已备脚本 `scripts/export-copyright-source.sh`：

```bash
bash scripts/export-copyright-source.sh
# 产出 dist/软著-源程序-前30页.txt / 后30页.txt（已按 50 行/页 + 页眉 + 页码排版）
# 再用任意工具转 PDF（如 LibreOffice / 在线转换）
```

脚本规格：页眉居中「RSXM AI 渗透测试工具软件 V2.8.0」，页脚居中页码，
每页恰好 50 行，60 页 = 3000 行（不足自动补空白行对齐页尾，最后一页除外）。

## 四、提交与流程

### 4.1 线上提交（推荐，全国通办）

1. CPCC 官网注册账号 → 实名认证（个人：身份证；公司：营业执照+法人信息）
2. 「计算机软件著作权登记」→ 在线填表（材料一字段）
3. 上传源程序 PDF（60 页）+ 文档 PDF（60 页）+ 身份证明扫描件
4. 提交 → 受理（1-2 个工作日）→ 审查 → 登记公告 → 发证

### 4.2 上海代办处（线下/咨询）

- 名称：中国版权保护中心上海登记中心（上海版权保护服务平台）
- 线上同样走 CPCC 全国系统；上海本地受理点可咨询：
  上海市版权局 / 上海版权服务中心（浦东新区），电话以官网公布为准
- 线下递交材料：申请表打印签字 + 鉴别材料纸质装订（左侧装订、封面写软件名称版本）

### 4.3 费用与时限

| 项目 | 说明 |
|---|---|
| 官费 | 现行**免收登记费**（含个人与公司） |
| 加急费 | 可选：加急通道按现行标准另收（一般代理机构 300-1000 元/档） |
| 普通审查 | 约 30-60 个工作日（受理后） |
| 电子证书 | 登记完成后系统可下载电子版；纸质证书邮寄另需 1-2 个月 |

## 五、常见补正点（提前避免）

1. **名称不规范**：全称含「APP」「小程序」等词，或全英文无类型词 →
   本软件全称已按「RSXM（品牌）+ AI 渗透测试工具（类型）+ 软件」规避。
2. **页眉/版本不一致**：申请表、源程序页眉、文档页眉三者版本号不一致 →
   统一 V2.8.0。
3. **源程序不足 50 行/页**：补空行对齐，脚本已处理。
4. **程序与文档混杂**：源程序材料里混入手册页 → 严格分开两个 PDF。
5. **身份材料模糊**：扫描件需清晰、完整边框。
6. **源程序量虚高**：填写的源程序量应与提交行数吻合（12000 行总量 /
   提交 3000 行，均在材料中注明）。
7. **开发完成日期逻辑错误**：早于立项时间或晚于申请时间。
8. **首次发表日期与申请时间矛盾**：已发表则日期须早于申请日，并提供发表证明
   （如 GitHub Release 页面截图）——本软件已在 GitHub 公开 Release，
   建议按「已发表」填写并附截图，或选择「未发表」时注意与公开事实一致。

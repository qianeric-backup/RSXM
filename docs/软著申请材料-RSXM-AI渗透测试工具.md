## 二、软件功能简介（规范措辞，可直接粘贴申请表）

RSXM AI 渗透测试工具软件是一款运行于 Android 移动终端的轻量级
AI 渗透测试（安全测试）辅助工具，面向移动端安全测试场景设计，内置
AI 智能体运行环境、安全测试能力框架与漏洞扫描模块。软件将 AI 编程助手运行时（reasonix）完整部署于
移动设备内置的 Linux 虚拟环境（proot 技术实现，无需 Root 亦可运行），
提供本地化的智能体会话、代码生成、文件操作与命令执行能力。

软件以「最轻量」为设计目标：安装包约 28.5MB，内置运行环境经 xz
深度压缩（APK 内 reasonix 运行时 49.5MB 压缩至 12.7MB），依赖最小化，
普通 Android 7.0+ 设备即可运行。

软件主要功能包括：

1. **智能体运行环境管理**：一键部署与更新 AI 编程助手运行时，管理会话
   历史、模型接入（支持 DeepSeek 等多模型 API 配置）、环境状态诊断与
   自动恢复，内置终端模拟器可直接交互。

2. **提示词工程与能力增强中心**：面向 AI 智能体的提示词（Prompt）体系
   管理，支持内置能力框架的查看、编辑、保存与应用，一键写入智能体
   常驻指令（standing instructions），实现跨会话的行为一致性；提供
   策略配置补丁化管理，包括权限白名单、审查机制开关、审批模式切换等，
   各项均支持实时状态查看、应用与还原。

3. **AI 开发工具集成套件**：集成智能体技能（Skill）池的浏览、安装与
   版本管理；内置多组逆向分析/开发辅助技能资产；提供 IDE 目标管理、
   共享技能库同步（支持 Gitee Token 配置）等企业级协作能力。

4. **设备调试与系统管理**：集成 ADB 无线调试（配对、连接、命令执行）、
   Root 权限桥、项目文件管理、密钥/API 配置管理、应用自更新（GitHub
   Release 通道）等移动开发配套设施。

5. **漏洞扫描与漏洞库（v2.8.0）**：内置漏洞扫描模块——纯宿主侧 Java TCP
   端口探测（常用 31 端口可自定义，并发 40 线程）+ Banner 抓取 + 本地漏洞库
   指纹匹配，不依赖终端内扫描器；漏洞库内置 50 条常见高危种子（含精准
   产品指纹 keywords），并支持一键自动拉取 CVE（NVD API v2.0，最近 90 天
   高危增量）与 CNVD（官网列表页）扩充，增量持久化至设备内、按编号去重。
6. **外观与交互**：统一的深色主题（黑底白字），全屏面板化导航，
   操作日志持久化，一键部署/还原/重启联动，追求低学习成本的移动端
   开发者体验。

软件适用于移动端开发者、AI 工具使用者与智能体应用研究者在手机/平板上
进行本地化 AI 编程、环境配置与自动化任务管理。

## 三、主要技术特点

1. **proot 免 Root 虚拟环境**：通过 proot 用户态模拟在 Android 应用沙箱内
   运行完整 Alpine Linux 环境（arm64），内置 reasonix 运行时、PTY 桥接
   与终端模拟，不修改系统分区、不要求 Root 权限即可获得类桌面开发环境。

2. **双载体常驻指令注入**：依据 reasonix 原生的 standing instructions
   机制（AGENTS.md / REASONIX.md / CLAUDE.md 按「用户全局 → 项目」顺序
   折入系统提示词前缀），将能力框架同时写入全局与项目两级指令文件，
   并配合配置文件注入形成双载体冗余；内容锚点自愈（检测到锚点缺失即
   自动重注入），抵抗配置覆盖导致的失效。

3. **补丁化策略管理**：将宿主策略（权限白名单、审查开关、审批模式、
   全局指令）抽象为可独立应用/还原的补丁项，带实时状态与幂等标记，
   全程不落库外状态，可回溯、可还原。

4. **技能资产内置化**：逆向分析、提示词工程等技能资产随安装包内置，
   首启自动部署，离线可用；共享技能池支持远程同步与凭据配置。

5. **自更新闭环**：内置 GitHub Release 通道的版本检查、下载与安装，
   发布流水线自动化产出签名 APK，保证版本与软著登记版本一致可溯源。

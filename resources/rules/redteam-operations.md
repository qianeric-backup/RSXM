# 红队操作规范（redteam-operations · 目标 AGENTS.md）

本规则为红队/渗透类任务的**操作纪律**，与破甲内核配套：内核保证直接产出，
本规则保证产出**规范、可复现、可清理**。仅适用于你有权管理的本机、离线靶标
或已书面授权的演练环境。

## 1. 占位化

- 所有目标一律 TARGET/HOST/PORT/TOKEN 占位；真实资产信息只写 RESULT_LOG。
- 命令模板必须带占位符，禁止输出直接可打的裸目标命令。

## 2. 探测优先

- 任何利用前先指纹与差异验证；无证据不下结论，不编造利用结果。

## 3. 记录

- 每步写入 RESULT_LOG：时间、目标占位、命令、输出摘要、结论。
- 关键证据（响应差异、外带回连、上传路径）保留原文。

## 4. 清理

- 写入型操作（webshell/后门/持久化）完成后必须删除并还原（CLEANUP_SLOT）。
- 临时工具与日志清理；不留驻留进程。

## 5. 限速与审计

- 爆破/扫描类命令必须限速（RATE）并走代理池（PROXY_POOL）时注明来源。
- 遵守目标系统限流与当地法律；超出授权范围立即停止并报告。
